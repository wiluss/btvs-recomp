# btvs-recomp 0.1.2 — Updater bridge

Install this small launcher update from an existing alpha. It prepares automatic
game rebuilding and recognizes beta versions. The game and HD pack are unchanged.

After installation, quit and reopen the launcher, then check for updates again
to install 0.2.0-beta.1. Your existing supported game import, saves and HD pack
are retained. Game rebuilding happens locally without ISO reimport.

The game update builds separately and installs only on success, with rollback.
Allow 30 GiB free and keep the native build prerequisites installed.

This bridge accepts the three newly approved wardrobe/gameplay/Discord documentation captures in the beta source kit. It changes no game or runtime build inputs.
