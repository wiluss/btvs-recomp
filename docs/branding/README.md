# Project branding

The user supplied an original monochrome Buffy logo as the reference and requested replacement lettering for btvs recomp. The selected transparent PNG was produced with the built-in image editor, retaining the characteristic B, gothic lettering and underline treatment. The original user reference and rejected drafts are not included in Git.

`moon.png` is the isolated pale violet moon from the original game-logo reference, prepared with the built-in image editor; the portions originally covered by lettering were reconstructed. The user explicitly requested this moon behind the existing wordmark. The wordmark PNG remains byte-for-byte unchanged. `logo-display.svg` layers the two images on a dark violet surface and performs no external requests. The launcher uses the same layout and presents the moon in color, with the wordmark in light-silver ink. The README and launcher use matching light-silver gradients, bright upper-left edges and darker offset shadows to give the lettering a raised, metallic appearance. These effects are presentation layers; both PNG assets remain unchanged. The navigation buttons and status strip are original SVG source graphics in violet and red.

Only these selected project-branding files are allowed in Git and the source kit. This exception does not permit game textures, fonts, HD packs or arbitrary images in source. The title-inspired wordmark is not covered by a grant of rights over the original Buffy artwork or trademarks. This is an unofficial project without claimed rights-holder endorsement.
